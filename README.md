# Notion Content Calendar: User Documentation

A self-initiated portfolio project showing task-based documentation for a no-code tool. It is not affiliated with or endorsed by Notion.

## Project overview
- **Audience:** Freelancers and small business owners with no technical background
- **Goal:** Help a first-time user build and manage a content calendar in Notion
- **Scope:** One getting-started guide, two how-to articles, and one troubleshooting page
- **Tools:** Notion, Markdown, Git

## Documents
1. Build your first content calendar in Notion (in progress)
2. How to add properties to a database (in progress)
3. How to filter and sort your calendar (in progress)
4. Troubleshooting (in progress)

## Style rules I followed
- Every step starts with a verb
- Interface labels are in bold
- One action per step
- Active voice and direct address ("you")
